# 获取帮助 / Support

## 使用问题

仓库公开后，请先阅读 [README](README.md)、[部署指南](docs/DEPLOYMENT.md)、[已知限制](docs/KNOWN_LIMITATIONS.md)，再搜索已有 Issues。可复现的问题请使用 Bug report 表单；功能想法使用 Feature request 表单。中文或英文均可。

提交日志、截图或配置前必须删除真实儿童姓名、照片、学校、学习记录、家庭标识、域名、IP、密码、API key 和数据库内容。请用 [`examples/demo-backup.json`](examples/demo-backup.json) 中的虚构数据复现。

## 安全问题

漏洞不要公开提交。仓库公开并开启 Private Vulnerability Reporting 后，请使用 **Security → Report a vulnerability**，并遵循 [SECURITY.md](SECURITY.md)。

## English

After the repository is public, search existing issues and read the README, deployment guide, and known limitations before filing a bug or feature request. Chinese and English are both welcome. Use synthetic data only and remove every child, family, credential, hostname, and provider identifier from diagnostics. Report security vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
