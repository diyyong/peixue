# Roadmap

Roadmap 项目按优先级组织，不代表固定发布日期。公开 Issue 后，应把每一项链接到可讨论、可验证的 Issue。

## Now：达到完整开源首发标准

- 建立匿名演示数据和界面截图
- 扩展家庭隔离、认证、导入/导出和数据库迁移回归测试
- 在干净环境验证 Docker Compose 安装、备份与恢复
- 轮换生产凭据并完成版权、MIT 许可证选择确认

## Next：降低自托管和贡献门槛

- 建立文本/视觉模型供应商兼容性矩阵
- 增加配置验证和更明确的启动错误
- 增加数据保留、删除与家庭自助管理能力
- 改进移动端可访问性、键盘操作和错误恢复
- 自动生成变更日志、Release 资产与升级说明

## Later：可验证的学习与社区能力

- 提供隐私友好的本地学习趋势摘要
- 允许维护者分享完全匿名、可复用的教学提示与题型适配
- 扩展国际化框架，同时保持中文家庭场景的设计深度
- 建立可选、明确同意且不收集儿童内容的部署采用统计

路线优先级会根据真实用户反馈、安全影响和维护能力调整。
